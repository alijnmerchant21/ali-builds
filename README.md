# Ali Builds

Things I build to explain new tech. The hub lives at https://ali-the-curios.dev/builds

Each build has its own folder with an `index.html`:

```
index.html            sends visitors to the hub
paperclip/index.html  https://alijnmerchant21.github.io/ali-builds/paperclip/
```

To add a build, create a new folder with its own `index.html` and push.

Every build is unofficial and not affiliated with the company it features.
